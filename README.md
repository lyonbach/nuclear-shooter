# Nuclear Shooter

A browser-based, top-down helicopter shooter. Survive incoming waves, destroy enemy armor, and collect field repairs.

## Play locally

Open `index.html` in a browser, or serve this directory with any static web server.

- **Move:** WASD or arrow keys
- **Aim:** mouse
- **Fire:** hold the left mouse button or Space
- **Touch:** use the on-screen movement and fire controls; the helicopter aims at the nearest enemy.

## GitHub Pages

The included workflow deploys the site on pushes to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The site will be available at `https://lyonbach.github.io/nuclear-shooter/`. All asset paths are relative, so the game also works under a different repository name.
